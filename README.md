# 🏋️ IronPlan — Telegram Mini App (Плани & Тренування в залі)

Сучасний додаток для Telegram, який працює **24/7 автономно (навіть коли комп'ютер вимкнений)** та безкоштовно розгортається на хмарному хостингу.

---

## ⚡ Головні можливості

1. 📅 **Щоденний планувальник (Плани на день)**
   - Перемикання: *Вчора*, *Сьогодні*, *Завтра* або будь-яка дата через календар.
   - Категорії (🏋️ Зал, 🎯 Ціль, 💼 Справи, 🏠 Дім) та пріоритети (🔥 Важливо).
   - Лічильник серії днів поспіль (Streak 🔥).
   - Кнопка в 1 клік: *«Перенести невиконані плани на завтра»*.
   - Салют (confetti) при виконанні всіх задач за день.

2. 🏋️ **Трекер тренувань (Зал)**
   - Готові спліти: *«Трьохденний Спліт»* (Груди/Тріцепс, Спина/Біцепс, Ноги/Плечі) та *«Full Body»*.
   - Можливість створити свою програму або додати будь-які свої вправи.
   - **Режим живого тренування (Live Workout)**:
     - Загальний таймер тривалості тренування.
     - Запис ваги (кг) та повторень для кожного підходу.
     - Зручні швидкі кнопки `+2.5` / `-2.5` кг (не треба щоразу відкривати клавіатуру спітнілими руками!).
     - 🔥 **Кнопка «Як минулого разу»**: миттєво підставляє робочі ваги з твого попереднього тренування цієї вправи!

3. ⏱ **Таймер відпочинку між підходами (Rest Timer)**
   - Автоматично спливає при позначці підходу як виконаного.
   - Звуковий сигнал (Web Audio API) та тактильна вібрація Telegram Haptic.
   - Кнопка швидкого додавання `+30с`.

4. 📈 **Прогрес & Калькулятор 1ПМ**
   - Розрахунок разового максимуму (1 Rep Max) за перевіреними формулами.
   - Таблиця робочих відсотків (90%, 85%, 80%...).
   - Історія тренувань та динаміка робочої ваги у кожній вправі.

5. ☁️ **Повна автономність (Telegram CloudStorage)**
   - Усі дані автоматично синхронізуються з хмарою Telegram користувача.
   - Додаток працює на телефоні з вимкненим ПК.
   - Можливість експорту та імпорту резервної копії в один клік (JSON).

## 🚀 Як залити на безкоштовний хостинг (за 2 хвилини)

### Варіант 1: Через Vercel CLI (найшвидший)

1. Відкрий термінал у папці `gym-planner-tma`:
   ```bash
   cd gym-planner-tma
   npx vercel
   ```
2. Обери створення проекту (натискай `Enter` на всі питання).
3. Vercel видасть тобі готове безкоштовне посилання з HTTPS, наприклад:
   `https://ironplan-tma.vercel.app`

### Варіант 2: Через GitHub + Vercel Web
1. Завантаж папку на свій GitHub.
2. Зайди на [vercel.com](https://vercel.com) (безкоштовно через GitHub).
3. Натисни **Add New Project** → обери свій репозиторій → **Deploy**.

---

## 🤖 Як підключити додаток до Telegram бота (BotFather)

1. Відкрий бота **@BotFather** у Telegram.
2. Напиши `/mybots` і обери свого бота (або створи нового через `/newbot`).
3. Перейди в меню:
   **Bot Settings** → **Menu Button** → **Configure menu button**.
4. Надішли посилання від Vercel (наприклад, `https://ironplan-tma.vercel.app`).
5. Введи назву кнопки, наприклад: `🏋️ IronPlan`.
6. Готово! Тепер при вході в бот зліва внизу буде кнопка, яка миттєво відкриває додаток на весь екран.
